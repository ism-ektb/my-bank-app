# Приложение "Демо Банк" 
# Модуль 3 / Спринт 9. Разработка приложений с использованием микросервисной архитектуры

Для запуска проекта требуется среда разработки для сборки и Docker для его запуска на локальном компьютере

1. Необходимо клонировать проект на локальный компьютер.
2. Зайти в папку 'my-bank-app'
3. Сменить ветку с 'main' на 'sprint_9'
4. Открыть проект в среде разработки и собрать командой "gradle clean build". Каждый микросервис будет собран в своем модуле.
5. Находясь в директории 'my-bank-app', выполнить команду "docker-compose up -d"

Запуск занимает продолжительное время. У меня на компьютере он занимает несколько минут. 
Контейнеры с основным приложением запускаются только после полной загрузки сервера авторизации keycloak.
Можно перейти по адресу http://localhost:8500 и убедиться что все сервисы зарегистрировались.

## Приложение будет доступно по порту 8084.

Для запуска приложения необходимо перейти по адресу http://localhost:8084
Должно появиться окно авторизации keycloak. При первом запуске необходимо выбрать пункт "регистрация"
Ввести "Электронную почту" и пароль. Можно ввести любое валидное значение электронной почты.
Электронная почта будет являться логином для последующих авторизаций.

UI приложения взят из задания. 
## В правом верхнем углу имеется кнопка выхода из аккаунта.
Можно выйти и зарегистрироваться под другим аккаунтом.
